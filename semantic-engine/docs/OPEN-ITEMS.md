# موارد باز، ناقص و انجام‌نشده

تاریخ: ۲۰۲۶-۱۰-۲۴ · مبنا: `main` در `legionir/semantic-engine` بعد از مرج PR #4 (`f3e569d`) و تغییرات PR جاری

این تنها فایل پیگیری کارهای باقی‌مانده است. گزارش‌های وضعیت فازها، پوشه‌های evidence، اسکریپت‌ها و fixtureهای regate و سندهای پلن/پرامپت که کارشان تمام شده بود از درخت حذف شدند و در تاریخچهٔ git (commit `0d8d4cf`) هستند.
هر مورد مربوط به ریپوی `semantic-engine-structured-ai` عمداً کنار گذاشته شده و اینجا نیست.

## ۱. پرفرمنس

| مورد | وضعیت و جزئیات |
|---|---|
| هدف‌های ۶ s / ۲ s | گیت واقعی طبق D-0030 «سرد ≤ ۸ s و ایندکس مجدد ≤ ۵ s» است (ران‌ر: ۷٫۶۵ / ۴٫۹۳). رسیدن به ۶ / ۲ نیاز به parse موازی (worker thread برای tree-sitter)، اشتراک AST بین مرحله‌ها (هزینهٔ حافظه) یا ایندکس افزایشی کامل (ریسک برابری) دارد و فقط با نیاز واقعی توجیه دارد. زمان باقی‌مانده: GC، دو parse دوبارهٔ TypeScript، ساخت گراف‌ها و ایندکس (≈۱٫۱ s هرکدام)، نوشتن ۴۸ مگابایت JSON (≈۱٫۵ s) |
| بنچمارک و eval روی یک مخزن | فقط خود پروژه اندازه گرفته شده؛ مخزن بزرگ یا چندزبانه ممکن است سهم مرحله‌ها را عوض کند |
