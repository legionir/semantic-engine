# موارد باز، ناقص و انجام‌نشده

تاریخ: ۲۰۲۶-۱۰-۲۳ · مبنا: `main` در `legionir/semantic-engine` بعد از مرج PR #2 (`0d8d4cf`)

این تنها فایل پیگیری کارهای باقی‌مانده است. گزارش‌های وضعیت فازها، پوشه‌های evidence، اسکریپت‌ها و fixtureهای regate و سندهای پلن/پرامپت که کارشان تمام شده بود از درخت حذف شدند و در تاریخچهٔ git (commit `0d8d4cf`) هستند.
هر مورد مربوط به ریپوی `semantic-engine-structured-ai` عمداً کنار گذاشته شده و اینجا نیست.

## ۱. پرفرمنس

| مورد | وضعیت و جزئیات |
|---|---|
| هدف ایندکس سرد زیر ۶ ثانیه | نشد؛ حدود ۷ تا ۸ ثانیه. زمان باقی‌مانده پخش است: GC، دو parse دوبارهٔ TypeScript (گراف فراخوانی و متریک)، ساخت گراف‌ها (≈۱٫۱ s)، ساخت ایندکس (≈۱٫۱ s)، نوشتن ۴۸ مگابایت JSON (≈۱٫۵ s). گزینه‌ها: worker thread برای tree-sitter، اشتراک AST بین مرحله‌ها (هزینهٔ حافظه)، ایندکس افزایشی کامل (ریسک برابری) |
| هدف ایندکس مجدد زیر ۲ ثانیه | نشد؛ ۵٫۳ ثانیه (کش استخراج فقط مرحلهٔ استخراج را حذف می‌کند) |
| خط پایهٔ بنچمارک | هنوز روی عدد قبل از کش استخراج است؛ از اجرای ران‌ر دوباره ثبت شود (`node scripts/bench.js --write`). gate فعلی بهبود را قفل نمی‌کند |
| بنچمارک و eval روی یک مخزن | فقط خود پروژه اندازه گرفته شده؛ مخزن بزرگ یا چندزبانه ممکن است سهم مرحله‌ها را عوض کند |
